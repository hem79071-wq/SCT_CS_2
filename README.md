🖼️ Task 02: Image Encryption using Pixel Manipulation – Project Overview

📌 Objective:
The objective of this task is to develop a simple image encryption tool that secures images by modifying their pixel values.

The project focuses on protecting image data from unauthorized access using basic encryption techniques.

🛠 Tools & Technologies Used:
Python – Core programming language
Google Colab – Development and testing platform
Pillow (PIL) – Image processing library
GitHub – Version control and project hosting.

⚙️ How the Project Works:
The user uploads an image.
The program reads the image and extracts pixel values.

Encryption is performed using pixel manipulation techniques such as:
Swapping RGB pixel values
Applying a mathematical operation (e.g., addition, subtraction, XOR) on each pixel
The encrypted image becomes visually unreadable.

The same logic is applied in reverse to decrypt the image and restore the original.

🔑 Key Features:

Simple image encryption and decryption
Uses pixel-level manipulation
Maintains image dimensions
Demonstrates reversible encryption logic.

🔐 Cybersecurity Relevance:

Images often contain sensitive information. This task demonstrates:
Basic concepts of data confidentiality
How encryption protects multimedia data
Foundations of image-based security systems
This project helps in understanding how encryption can be applied beyond text, which is crucial in cybersecurity.
